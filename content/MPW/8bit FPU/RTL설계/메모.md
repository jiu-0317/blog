# 1clk pulse generator

![[Pasted image 20260524162511.png]]

```verilog
module pulse_detector (
    input  wire clk,
    input  wire rst_n,
    input  wire sig_in,
    output wire pulse_out
);

    reg sig_d;

    always @(posedge clk or negedge rst_n) begin
        if (!rst_n)
            sig_d <= 1'b0;
        else
            sig_d <= sig_in;
    end

    assign pulse_out = sig_in & ~sig_d;

endmodule

```
