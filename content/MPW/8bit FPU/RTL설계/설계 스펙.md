# Control Signal

**Datapath --> Control**

| 신호           | 폭   | 출처        | 설명               |
| ------------ | --- | --------- | ---------------- |
| cmd_valid    | 1   | IR        | 새 command 도착     |
| w_all_valid  | 1   | RF        | weight 9개 모두 채워짐 |
| i_all_valid  | 1   | RF        | input 9개 모두 채워짐  |
| fpu_done     | 1   | FPU       | 연산 완료            |
| fpu_rf_valid | 1   | Output RF | FPU 결과 저장 완료     |
| acc_done     | 1   | ACC       | 1회 누적 완료         |
| or_rf_valid  | 1   | OR        | 누적 결과 저장 완료      |

**Control --> Datapath**

| 신호             | 폭   | 대상            | 설명                                |
| -------------- | --- | ------------- | --------------------------------- |
| rf_w_wen       | 1   | RF            | weight write enable               |
| rf_i_wen       | 1   | RF            | input write enable                |
| fpu_start      | 1   | FPU ×9        | 연산 유효 신호                          |
| out_rf_wen     | 1   | Output RF     | FPU 결과 저장                         |
| acc_sel        | 4   | ACC           | MUX 선택 (카운터 값)                    |
| or_wen         | 1   | OR            | 결과 저장                             |
| rf_clear_valid | 1   | RF, Output RF | input valid + output RF valid 초기화 |
