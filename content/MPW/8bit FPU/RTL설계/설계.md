# FP8 MAC (Multiply-Accumulate) Unit 설계 계획

## Context
기존 `fp8_multiplier`(mode_select.v)와 `SPI_slave`(SPI_slave.v)를 활용하여, 9개의 가중치와 9개의 스트리밍 입력을 순차적으로 곱하고 누적(dot product)하는 MAC 유닛을 설계한다.

**핵심 설계 결정:**
- FPU 1개 시분할 (9 cycle) → 면적 최소화
- 각 채널별 독립 모드 (E5M2/E4M3) 지원
- 혼합 포맷 누산을 위해 내부 고정소수점(fixed-point) 누산기 사용
- 출력 포맷은 SPI 명령으로 별도 지정

## 전체 아키텍처
```
[SPI Master] → SPI_slave → spi_decoder → 명령 분기
                                           ├─ LOAD_WEIGHT  → weight_regs[addr] + mode_regs[addr]
                                           ├─ STREAM_DATA  → controller 트리거
                                           ├─ SET_OUT_FMT  → output_mode 레지스터
                                           ├─ RESET_ACC    → ACC 초기화, cnt 리셋
                                           └─ READ_ACC     → SPI로 ACC 값 반환

[연산 경로 (STREAM_DATA 수신 시)]
weight_regs[cnt] ──┐
mode_regs[cnt] ────┤
                   ├─→ fp8_multiplier ─→ fp8_to_fixed ─→ fixed_adder ─→ acc_reg(36b)
streaming_data ────┘                                        ↑
                                                        acc_reg (feedback)

[출력 경로 (READ_ACC 시)]
acc_reg(36b) ─→ fixed_to_fp8(output_mode) ─→ o_result[7:0] / SPI MISO
```

## SPI 프로토콜 (32-bit 프레임)
| Bits | 필드 | 설명 |
|------|------|------|
| [31:28] | CMD | 명령코드 |
| [27:24] | ADDR | 가중치 주소 (0~8) |
| [23:9] | Reserved | 미사용 |
| [8] | MODE | 채널 모드 (LOAD_WEIGHT 시 사용) |
| [7:0] | DATA | 8-bit FP8 데이터 |

**CMD 코드:**
| CMD | 이름 | 동작 |
|-----|------|------|
| 4'b0001 | LOAD_WEIGHT | weight_regs[ADDR]=DATA, mode_regs[ADDR]=MODE |
| 4'b0010 | STREAM_DATA | DATA와 weight[cnt] 곱셈→고정소수점 변환→ACC 누적, cnt++ |
| 4'b0011 | READ_ACC | ACC를 output_mode 포맷으로 변환하여 SPI 반환 + o_result 갱신 |
| 4'b0100 | RESET_ACC | ACC=0, cnt=0 |
| 4'b0101 | SET_OUT_FMT | output_mode = DATA[0] (0:E5M2, 1:E4M3) |

## 모듈 정의

### 1. SPI_slave (기존, 수정 없음)
파일: `SPI_slave.v`
- **기능**: 32-bit SPI 통신
- **입력**: i_rstn, i_clk, i_SSn, i_MOSI, i_SCLK, i_dat[31:0]
- **출력**: o_MISO, o_dat[31:0]

### 2. fp8_multiplier (기존, 수정 없음)
파일: `mode_select.v`
- **기능**: FP8 곱셈 (E5M2/E4M3 모드 선택)
- **입력**: mode, a[7:0], b[7:0]
- **출력**: result[7:0]

### 3. spi_decoder (신규)
- **기능**: SPI 수신 데이터(32b)를 명령/주소/모드/데이터로 분리, SSn rising edge에서 유효 펄스 생성
- **입력**:
  - i_clk, i_rstn
  - i_spi_data[31:0] — SPI_slave.o_dat
  - i_ssn — SS 신호 (rising edge 검출용)
- **출력**:
  - o_cmd[3:0], o_addr[3:0], o_mode, o_data[7:0]
  - o_cmd_valid — 1-cycle 펄스

### 4. weight_regs (신규)
- **기능**: 9×8-bit 가중치 + 9×1-bit 모드 저장 (총 81 bits)
- **입력**:
  - i_clk, i_rstn
  - i_we — 쓰기 인에이블
  - i_waddr[3:0] — 쓰기 주소 (0~8)
  - i_wdata[7:0] — 가중치
  - i_wmode — 해당 채널 모드
  - i_raddr[3:0] — 읽기 주소
- **출력**:
  - o_rdata[7:0] — 가중치
  - o_rmode — 해당 채널 모드

### 5. fp8_to_fixed (신규)
- **기능**: FP8 (E5M2 or E4M3) → 36-bit signed fixed-point (Q19.16) 변환
- **입력**: i_mode, i_fp8[7:0]
- **출력**: o_fixed[35:0]
- **내부 로직**:
  1. 부호/지수/가수 언팩 (mode에 따라)
  2. full_mantissa = {is_normal, mant} (3~4 bits)
  3. shift_amount 계산:
     - E5M2 normal: exp - 1
     - E5M2 subnormal: 0
     - E4M3 normal: exp + 6
     - E4M3 subnormal: 7
  4. 배럴 시프터로 full_mant를 left shift
  5. 부호 적용 (2의 보수)
- **면적**: 5-stage barrel shifter (max shift 29) + 부호 로직

### 6. fixed_to_fp8 (신규)
- **기능**: 36-bit signed fixed-point → FP8 (E5M2 or E4M3) 변환
- **입력**: i_mode, i_fixed[35:0]
- **출력**: o_fp8[7:0]
- **내부 로직**:
  1. 부호 추출, 절대값 계산
  2. Leading-one detector (35-bit) → 위치 = 지수 결정
  3. 가수 비트 추출 + 반올림 (RNE)
  4. 지수/가수 → FP8 포맷 패킹 (mode에 따라)
  5. 오버플로/언더플로 처리:
     - E5M2 overflow → Inf, E4M3 overflow → max normal (448)
     - Underflow → 0
  6. 특수 케이스: 입력 0 → 출력 0

### 7. controller (신규)
- **기능**: FSM 및 데이터패스 제어
- **상태**: IDLE → COMPUTE → IDLE (2-state FSM)
- **입력**:
  - i_clk, i_rstn
  - i_cmd[3:0], i_cmd_valid, i_addr[3:0], i_mode, i_data[7:0]
  - i_mult_result[7:0] — fp8_multiplier 출력
  - i_fixed_conv[35:0] — fp8_to_fixed 출력
- **출력**:
  - o_weight_we, o_weight_waddr[3:0], o_weight_wdata[7:0], o_weight_wmode
  - o_weight_raddr[3:0] — 자동 순환 카운터 (0→8→0)
  - o_mult_a[7:0], o_mult_b[7:0], o_mult_mode
  - o_fp8_to_fixed_input[7:0], o_fp8_to_fixed_mode
  - o_acc[35:0] — 36-bit 누산기
  - o_output_mode — 출력 포맷 (E5M2/E4M3)
  - o_result[7:0] — 최종 FP8 결과
  - o_valid — 연산 완료 1-cycle 펄스
  - o_busy
  - o_spi_rdata[31:0] — SPI 읽기 데이터

### 8. fp8_mac_top (Top Module)
- **기능**: 전체 시스템 통합

## 고정소수점 포맷 상세
- **형식**: 36-bit signed 2's complement, 16 fractional bits (Q19.16)
- **범위**: -2^19 ~ +2^19 - 2^(-16) ≈ ±524,288
- **정밀도**: 2^(-16) ≈ 0.0000153
- **9개 누적 최대**: 9 × 57,344 = 516,096 < 2^19 ✓ (E5M2 최대값 기준)
- **최소 표현**: 2^(-16) (E5M2 최소 subnormal) ✓

## 연산 타이밍
```
[STREAM_DATA 수신 시 - 1 clock cycle]
  ┌─ weight_regs[cnt] → mult.a
  ├─ streaming_data   → mult.b     } 조합논리:
  ├─ mode_regs[cnt]   → mult.mode  } mult → fp8_to_fixed → adder
  └─ posedge clk: acc <= acc + fixed_conv(mult_result)
                  cnt <= cnt + 1 (wrap at 8→0)
                  o_valid <= 1 (1-cycle pulse)

[READ_ACC 시 - 1 clock cycle]
  acc → fixed_to_fp8(output_mode) → o_result, SPI readback
```

## 면적 최소화 전략
1. **FPU 1개 시분할**: 곱셈기 9→1 (면적 ~89% 절감)
2. **고정소수점 누산**: FP8 adder 대신 36-bit integer adder (혼합 포맷 자연 처리)
3. **weight_regs**: 플립플롭 기반 (9×9=81 FF, SRAM 불필요)
4. **조합논리 컨버터**: fp8_to_fixed, fixed_to_fp8 레지스터 없음
5. **SPI로 mode 전달**: 별도 mode 핀 불필요
6. **최소 FSM**: 2-state (IDLE/COMPUTE)

## 구현 순서
1. `fp8_to_fixed` — FP8→고정소수점 변환기
2. `fixed_to_fp8` — 고정소수점→FP8 변환기
3. `spi_decoder` — SPI 명령 디코더
4. `weight_regs` — 가중치+모드 레지스터 파일
5. `controller` — FSM 및 데이터패스 제어
6. `fp8_mac_top` — 전체 통합
7. 테스트벤치 작성 및 시뮬레이션 검증

## 파일 구조
- `mode_select.v` — 기존 FP8 곱셈기 (수정 없음)
- `SPI_slave.v` — 기존 SPI 슬레이브 (수정 없음)
- `fp8_mac_top.v` — 신규 모듈 전체 + top module

## 검증 계획
1. 단일 모드 dot product: 9개 E5M2 가중치 × 9개 E5M2 스트리밍 → 결과 확인
2. 혼합 모드: 일부 E5M2, 일부 E4M3 가중치 → 고정소수점 누산 → E4M3 출력
3. ACC reset 후 재연산
4. 특수값 테스트 (NaN, Inf, Zero 입력)
5. 오버플로/언더플로 경계값
6. 연속 dot product (ACC running sum)
