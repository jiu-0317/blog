# Setup Time (tsu)

Setup time은 클럭 엣지가 도착하기 "전에" 데이터가 안정적으로 유지되어야 하는 최소 시간.

예를 들어 rising edge 트리거 FF라면, 클럭이 올라가기 전 tsu 동안 데이터 입력(D)이 변하면 안된다. 이걸 위반하면 setup violation이 발생하고, FF가 데이터를 제대로 래치하지 못해서 metastability 상태에 빠질 수 있다.

# Hold Time (th)

Hold time은 클럭 엣지가 도착한 "후에" 데이터가 안정적으로 유지되어야 하는 최소 시간.

클럭 엣지 이후에도 th 동안은 데이터가 바뀌면 안된다. 이걸 위반하면 hold violation이 발생한다.


# Slack 

## Timing Slack
Slack은 타이밍 여유를 나타내는 값.

Setup slack의 경우, 데이터가 실제로 도착한 시점과 setup time 데드라인 사이의 차이야. 식으로 쓰면:
- Setup Slack = (Required Arrival Time) − (Actual Arrival Time)

Hold slack도 비슷하게:
- Hold Slack = (Actual Arrival Time) − (Required Arrival Time)

두 경우 모두 slack이 양수(positive)면 타이밍을 만족하는 거고, 음수(negative)면 violation이야. STA(Static Timing Analysis) 도구에서 가장 중요하게 보는 지표 중 하나지.


# Slew
슬루(slew)는 신호가 한 전압 레벨에서 다른 전압 레벨로 전환되는 데 걸리는 시간입니다. transition time이라고도 합니다.

예를 들어 0V에서 5V(VDD)로 올라가는 rising 신호가 있을 때, 보통 VDD의 20%~80% 구간(또는 10%~90%)을 지나는 데 걸리는 시간을 슬루라고 합니다. falling도 마찬가지로 80%→20% 구간의 시간입니다.
