## 슬라이드 2-3: Top-Level Block Diagram + Timing Diagram

### Block Diagram (그려야 할 내용)

```
                         dct2d_4x4 (Top Module)
  ┌─────────────────────────────────────────────────────────────────┐
  │                                                                 │
  │   ┌──────────┐    ┌───────────────┐    ┌──────────────┐        │
  │   │ in_buf   │    │  dct1d_4pt_seq│    │  inter_buf   │        │
  │   │ [4][4]   │───>│  (u_dct1d)    │───>│  [4][4]      │        │
  │   │ 16-bit   │    │               │    │  16-bit      │        │
  │   └──────────┘    │  dct_x0..x3   │    └──────┬───────┘        │
  │        ↑          │  dct_y0..y3   │           │                │
  │   x00..x33        │  dct_start    │           │ Pass2          │
  │   (16개 입력)      │  dct_done     │           ↓                │
  │                    │  dct_ready    │    ┌──────────────┐        │
  │                    │               │<───│  MUX         │        │
  │                    └───────────────┘    │  (col select)│        │
  │                           │             └──────────────┘        │
  │                           ↓                                     │
  │                    ┌──────────────┐                              │
  │                    │  y00..y33    │                              │
  │                    │  (16개 출력)  │                              │
  │                    └──────────────┘                              │
  │                                                                 │
  │   ┌────────────────────────────────┐                            │
  │   │  Controller (FSM)              │                            │
  │   │  state[2:0], idx[1:0]         │                            │
  │   │                                │                            │
  │   │  S_IDLE → S_ROW_FEED →        │                            │
  │   │  S_ROW_WAIT → S_COL_FEED →    │                            │
  │   │  S_COL_WAIT → S_DONE          │                            │
  │   └────────────────────────────────┘                            │
  │                                                                 │
  │  Signals: clk, rst_n, start, done, ready                       │
  └─────────────────────────────────────────────────────────────────┘
```

**핵심 포인트:**

- **Single 1D DCT instance reuse**: 하나의 `dct1d_4pt_seq`를 Row-wise(Pass 1)와 Column-wise(Pass 2)에서 재사용
- **3개 버퍼**: `in_buf[4][4]` → 1D DCT → `inter_buf[4][4]` → 1D DCT → `y00~y33` (output registers)
- **MUX**: idx[1:0]에 의해 행/열 선택

### Timing Diagram (그려야 할 내용)

|신호|시간 흐름 →|
|---|---|
|`clk`|`⎍⎍⎍⎍⎍⎍⎍...`|
|`start`|`_⎍_____...` (1 cycle pulse)|
|`state[2:0]`|`IDLE → ROW_FEED → ROW_WAIT → ROW_FEED → ROW_WAIT → ROW_FEED → ROW_WAIT → ROW_FEED → ROW_WAIT → COL_FEED → COL_WAIT → ... → COL_WAIT → DONE → IDLE`|
|`idx[1:0]`|`0 → 0 → (row0 처리중) → 1 → (row1) → 2 → (row2) → 3 → (row3) → 0 → (col0) → 1 → ... → 3 → 0`|
|`dct_start`|Pass1: 4회 pulse, Pass2: 4회 pulse (총 8회)|
|`dct_done`|각 1D DCT 완료시 1 pulse (총 8회)|
|`done`|`___...⎍_` (최종 완료, 1 cycle pulse)|
|`ready`|`⎍__...___⎍` (IDLE일 때만 high)|

**총 Latency: 194 clock cycles** (start → done)

- Pass 1 (Row DCT): 4회 × (21 cycles + 2 cycles overhead) ≈ 96 cycles
- Pass 2 (Col DCT): 4회 × (21 cycles + 2 cycles overhead) ≈ 96 cycles
- State 전환 overhead: ~2 cycles

## 슬라이드 4-5: Datapath Block Diagram + Timing Diagram (1D DCT 모듈 단위)

### dct1d_4pt_seq Datapath Block Diagram

```
                    dct1d_4pt_seq
  ┌────────────────────────────────────────────────────────┐
  │                                                        │
  │   x0..x3 ──→ ┌──────────┐                             │
  │   (입력)      │ x_reg[4] │  (start시 래치)             │
  │               └────┬─────┘                             │
  │                    ↓                                   │
  │              ┌───────────┐                             │
  │   n_cnt ───→│ Input MUX │──→ x_sel (16-bit Q11.5)    │
  │              └───────────┘                             │
  │                    │                                   │
  │                    ↓                                   │
  │              ┌───────────┐   ┌───────────┐            │
  │              │ Multiplier│←──│ COS LUT   │            │
  │              │ 16×16→32  │   │ Q1.15     │            │
  │              └─────┬─────┘   │ 16 entries│            │
  │                    │         │ {v,n}→val │            │
  │                    ↓         └───────────┘            │
  │  product    ┌───────────┐                             │
  │  (32bit) ──→│ ACC (34b) │  n=0: load, n>0: += product│
  │             └─────┬─────┘                             │
  │                   ↓                                   │
  │            ┌──────────────┐                           │
  │            │ Round Q12.20 │                           │
  │            │  → Q11.5     │                           │
  │            └──────┬───────┘                           │
  │                   ↓                                   │
  │            ┌───────────┐   ┌───────────┐             │
  │            │ Multiplier│←──│ CSNT LUT  │             │
  │            │ 16×16→32  │   │ Q1.15     │             │
  │            └─────┬─────┘   │ v=0:16384 │             │
  │                  ↓         │ v≠0:23170 │             │
  │            ┌──────────┐    └───────────┘             │
  │            │ Round     │                              │
  │            │ → Q11.5   │                              │
  │            └─────┬─────┘                              │
  │                  ↓                                    │
  │            y_result ──→ y0, y1, y2, y3               │
  │                        (v_cnt로 선택)                  │
  └────────────────────────────────────────────────────────┘
```

**변수명 매핑:**

|Block Diagram|Verilog 변수|비트폭|설명|
|---|---|---|---|
|x_reg|`x_reg[0:3]`|16-bit signed|입력 래치 레지스터|
|Input MUX|`x_sel`|16-bit signed|n_cnt로 x_reg 선택|
|COS LUT|`cos_val`|16-bit signed Q1.15|cos(π(2n+1)v/8), 16 entries|
|Multiplier 1|`product`|32-bit signed|x_sel × cos_val|
|ACC|`acc`|34-bit signed|누적기 (overflow 보호)|
|Round 1|`acc_rnd`, `acc_q115`|34b → 16b|Q12.20 → Q11.5 반올림|
|CSNT LUT|`csnt_val`|16-bit signed Q1.15|c(v)×√(2/N)|
|Multiplier 2|`scaled`|32-bit signed|acc_q115 × csnt_val|
|Round 2|`scaled_rnd`, `y_result`|32b → 16b|최종 Q11.5 출력|

### 1D DCT Timing Diagram (1회 연산, v=0 기준)

```
Cycle:     1      2      3      4      5      6     ...
         ┌──────┬──────┬──────┬──────┬──────┬──────┐
state    │ COMP │ COMP │ COMP │ COMP │SCALE │ COMP │  (다음 v)
         └──────┴──────┴──────┴──────┴──────┴──────┘
n_cnt    │  0   │  1   │  2   │  3   │  0   │  0   │
v_cnt    │  0   │  0   │  0   │  0   │  0   │  1   │
cos_val  │cos00 │cos01 │cos02 │cos03 │  -   │cos10 │
x_sel    │x_r[0]│x_r[1]│x_r[2]│x_r[3]│  -   │x_r[0]│
product  │x0×c00│x1×c01│x2×c02│x3×c03│  -   │x0×c10│
acc      │ load │ +=   │ +=   │ +=   │  -   │ load │
y_result │  -   │  -   │  -   │  -   │ Y[0] │  -   │
```

**Per-v latency: 5 cycles** (4 cycles COMP + 1 cycle SCALE) **Total 1D DCT latency: 21 cycles** (4×5 + 1 done cycle)

## 슬라이드 6-7: Controller 설명

### Top Controller FSM (dct2d_4x4)

```
                    start
         ┌──────┐  ────→  ┌───────────┐
         │S_IDLE│         │S_ROW_FEED │←────────┐
         │(000) │         │(001)      │         │
         └──┬───┘         └─────┬─────┘         │
            ↑                   │               │
            │                   ↓               │
         ┌──┴───┐         ┌───────────┐    idx<3│
         │S_DONE│         │S_ROW_WAIT │─────────┘
         │(101) │         │(010)      │  dct_done
         └──────┘         └─────┬─────┘  & idx++
            ↑                   │
            │              idx==3│
            │              dct_done
            │                   ↓
            │            ┌───────────┐
            │            │S_COL_FEED │←────────┐
            │            │(011)      │         │
            │            └─────┬─────┘         │
            │                  │               │
            │                  ↓               │
            │            ┌───────────┐    idx<3│
            └────────────│S_COL_WAIT │─────────┘
              idx==3     │(100)      │  dct_done
              dct_done   └───────────┘  & idx++
```

**FSM 상태 설명:**

|상태|코드|동작|
|---|---|---|
|`S_IDLE`|000|대기. `start`시 `in_buf`에 16개 입력 래치, `idx←0`|
|`S_ROW_FEED`|001|`in_buf[idx][0..3]`을 `dct_x0..x3`에 로드, `dct_start←1`|
|`S_ROW_WAIT`|010|`dct_done` 대기. 완료시 결과를 `inter_buf[idx][0..3]`에 저장|
|`S_COL_FEED`|011|`inter_buf[0..3][idx]`을 `dct_x0..x3`에 로드, `dct_start←1`|
|`S_COL_WAIT`|100|`dct_done` 대기. 완료시 결과를 `y[0..3][idx]`에 저장|
|`S_DONE`|101|`done←1` 출력, `S_IDLE`로 복귀|

### 1D DCT Controller FSM (dct1d_4pt_seq)

```
               start
    ┌──────┐  ────→  ┌──────┐
    │S_IDLE│         │S_COMP│←──────┐
    │ (00) │         │ (01) │       │ v_cnt < 3
    └──┬───┘         └───┬──┘       │
       ↑                 │          │
       │            n==3 ↓          │
    ┌──┴───┐        ┌──────┐       │
    │S_DONE│←───────│S_SCALE│───────┘
    │ (11) │ v==3   │ (10) │
    └──────┘        └──────┘
```

|상태|코드|동작|
|---|---|---|
|`S_IDLE`|00|대기. `start`시 `x_reg`에 4개 입력 래치, `v_cnt←0`, `n_cnt←0`|
|`S_COMP`|01|`n_cnt`=0..3 순회. `x_sel × cos_val` → `acc`에 누적. 4 cycles|
|`S_SCALE`|10|`acc`를 반올림 후 `csnt_val`과 곱하여 `y[v_cnt]`에 저장. 1 cycle|
|`S_DONE`|11|`done←1`, `S_IDLE`로 복귀|

### Pipeline / 연산 흐름 요약

설계는 pipeline이 아닌 **순차 재사용(sequential reuse)** 방식:

- 1개의 1D DCT 하드웨어를 **8번 재사용** (4 rows + 4 columns)
- 1D DCT 내부도 1개의 곱셈기를 **16번 재사용** (4 elements × 4 frequency components)
- 총 Latency: **194 clock cycles** (8 × 21 cycle 1D DCT + state 전환 overhead)

## 슬라이드 10-11: 시뮬레이션 결과 — Random Access 입력

### 테스트벤치 설명

- 파일: `tb_dct2d_random.v`
- 방식: 블록 입력 사이에 **랜덤 delay** 삽입 (3, 7, 12, 1, 20 cycles)
- 5개 블록 처리

### 결과 요약

|Block|Pre-Delay|Start Cycle|Done Cycle|Latency|비고|
|---|---|---|---|---|---|
|Block1|3 cycles|5|199|194|기본 검증 데이터|
|Block2|7 cycles|206|400|194|감쇠 패턴|
|Block3|12 cycles|412|606|194|DC only (all 100)|
|Block4|1 cycle|607|801|194|다양한 값|
|Block5|20 cycles|821|1015|194|Single impulse (1,1)|

### 핵심 관찰

- **Delay에 무관하게 Latency 일정**: 194 cycles (설계의 결정적 동작 확인)
- **Block1 결과 동일**: Burst와 Random 모두 같은 출력 → 기능 정확성 검증
- **Block5 (impulse test)**: (1,1) 위치에 255, 나머지 0 → 2D DCT basis function 패턴 확인
- 총 시뮬레이션: **1015 cycles** (delay 포함)
